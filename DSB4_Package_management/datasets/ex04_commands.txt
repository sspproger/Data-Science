1.Профилирование с sleep
python -m cProfile -s tottime financial.py 'MSFT' 'Total Revenue' > profiling-sleep.txt

2.Профилирование без sleep
Удалить time.sleep(5) из financial.py:

python -m cProfile -s tottime financial.py 'MSFT' 'Total Revenue' > profiling-tottime.txt

3.Профилирование улучшенного скрипта HTTPX

python -m cProfile -s tottime financial_enhanced.py 'MSFT' 'Total Revenue' > profiling-http.txt

4.Профилирование по числу вызовов
python -m cProfile -s ncalls financial_enhanced.py 'MSFT' 'Total Revenue' > profiling-ncalls.txt

5.Использовать pstats 

Создаем бинарный файл профилирования:
python -m cProfile -o profile.prof financial_enhanced.py 'MSFT' 'Total Revenue'

Анализируем через pstats:
python -c "import pstats; stats = pstats.Stats('profile.prof'); stats.sort_stats('cumulative'); stats.print_stats(5)" > pstats-cumulative.txt

Профилирование — это процесс измерения производительности программы: сколько времени тратится на выполнение разных функций, сколько памяти используется, как часто вызываются те или иные части кода.

cProfile — это встроенный в Python профилировщик (модуль для анализа производительности кода). Он измеряет, сколько времени тратится на выполнение каждой функции в программе, сколько раз они вызываются.

pstats — это модуль в стандартной библиотеке Python для анализа и форматирования результатов профилирования, полученных через cProfile.
Он позволяет работать с файлами статистики профилирования (обычно с расширением .prof или .pstats) и выводить данные в удобном виде.

	Ключевые столбцы в выводе cProfile:

	ncalls — количество вызовов функции
	tottime — общее время, проведённое в функции (без учёта вызовов других функций)
	percall (первое) — tottime ÷ ncalls
	cumtime — кумулятивное время (включая время в вызываемых функциях)
	percall (второе) — cumtime ÷ ncalls
	filename:lineno(function) — где определена функция
